Riproducilo tu

Chiunque può rifare l'analisi e controllare di ottenere esattamente gli stessi file che abbiamo pubblicato: se le impronte SHA256 coincidono, il risultato è riprodotto. Non serve fidarsi di noi.

L'ultimo passo del calcolo, rifatto dal tuo browser

Premi il pulsante: il tuo browser legge l'esito di ogni paziente pubblicato nella sfera, conta i pazienti in cui il secondo campione cambia il farmaco in cima, ricalcola la quota e l'intervallo con la stessa formula del codice e li confronta, cifra per cifra, con il risultato registrato. Nessun file da scaricare, nessuna richiesta fuori da questo sito.

Il tuo browser rifà l'ultimo passo, dagli esiti dei pazienti al risultato. Il ricalcolo completo dai dati degli autori è la seconda strada, qui sotto: si accende quando il codice firmato e la prova con i dati veri sono registrati.

Strada 1: dal terminale

Strada 1: dal terminale

Con Python sul tuo computer: scarichi il codice, prendi i due file dello studio dagli autori (Mendeley Data, licenza CC BY 4.0), rifai l'analisi e confronti le impronte dei file che ottieni con quelle qui sotto.

Dal terminale

  1. Scaricare il codice: il repository sarà pubblico alla consegna; fino ad allora questo passo non si può fare da qui.
  2. Installare le librerie con le versioni esatte (stessi byte del certificato)pip install -r requirements-esatti.txt
  3. Rifare il controllo D8, prima dell'analisi (stesso comando dei risultati pubblicati)python -m src.d8_riproduzione --s5 data/raw/Data_S5.xlsx --out <cartella>
  4. Rifare l'analisi (stesso comando dei risultati pubblicati, nella stessa cartella di uscita del D8)python -m src.esegui_analisi_reale --s5 data/raw/Data_S5.xlsx --s1 data/raw/Data_S1.xlsx --audit evidence/replica_sessione/DATA_AUDIT.csv --out <cartella>
  5. Confrontare le improntesha256sum <cartella>/D8_riproduzione.csv <cartella>/analisi_*.csv results/D8_riproduzione.csv results/analisi_*.csv
